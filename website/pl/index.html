Uruchom na swoim komputerze

Uruchom w terminalu z Git i Node.js 22.18 lub nowszym. Otwórz https://localhost:3011 i dokończ konfigurację.

git clone https://github.com/cretli/cretli.git && cd cretli && npm ci && npm run build:front:prod && npm start

Cretli udostępnia pełny terminal. Zachowaj domyślny dostęp lokalny; przed udostępnieniem w zaufanej sieci LAN skonfiguruj HTTPS i uwierzytelnianie. Dokumentacja
