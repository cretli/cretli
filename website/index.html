Cretli – remote vibe coding on mobile

Self-hosted PWA for remote coding and AI agents — terminal and chat on your phone, talking to your own PC.

Cursor SDK, OpenRouter, or OpenCode — equal backends. Not affiliated with Anysphere or Cursor.

View on GitHub Star on GitHub

Security: Cretli exposes a full shell as your user. Default bind is localhost. Do not put it on the public internet. Read SECURITY.md.

MIT · Node 22+

Quick start

git clone https://github.com/cretli/cretli.git
cd cretli
npm install
npm run build:front:prod
npm start

Or Docker (publishes localhost:3011):

export CRETLI_SETUP_TOKEN="$(openssl rand -hex 16)"
docker compose up --build
Three chat backends
  • OpenCode (Zen / local auth)
  • OpenRouter
  • Cursor SDK (optional package, Cursor ToS apply)
Terminal, files, and git work with no API key.
