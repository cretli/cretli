Start on your own machine

Run this in a terminal with Git and Node.js 22.18 or newer. Then open https://localhost:3011 and complete setup.

git clone https://github.com/cretli/cretli.git && cd cretli && npm ci && npm run build:front:prod && npm start

Cretli provides a full shell. Keep the default local bind; configure HTTPS and authentication before enabling trusted LAN access. Documentation
