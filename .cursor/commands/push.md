# Command: push

Use this when the user asks to **push**, **commit and push**, or `/push`.

Default branch: `master`. Remote: `origin` (`github.com/cretli/cretli`).

1. Review status and diff in the repo root (do not commit unless the user asked).
2. Commit with a concise English message if requested.
3. Push as the repo owner (not as root if SSH keys belong to a desktop user).

Do not put private SSH key paths, home directories, or other machine-specific details in this file.
