                  Page widgets

                  Each installation is bound to one workspace and to the allowed page origins.

                  Embed Cretli on a project page. The widget ties agent chat to the current page (DOM, console, network, screenshot). Each installation is bound to one workspace.

                  1. Pick a workspace and create an installation below (name, allowed origins, permissions).
                  2. Copy the generated script tag and paste it before </body> on the project page.
                  3. Open the page from an allowed origin (e.g. a local dev server). Sign in in the Cretli authorization window on first use.
                  4. The widget shows a chat button. The chat session is bound to the page URL and context.

                  Security: HTTP is allowed only for localhost and private LAN addresses (e.g. http://192.168.1.10:8080). The origin must match exactly.

                  Page control: enable interact and navigate only when the agent should click, type, or reload the page.

                  Build: the widget bundle is served from /dist/app/embed-widget.bundle.js — keep the Cretli server running with a current production build.
